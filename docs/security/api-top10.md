# OWASP API Security Top 10 (2023)

Scope: `services/online-api` (public). Controls `C-xx` and tests `SEC-*` are defined in the
[threat model](threat-model.md). Status: ✅ done · 🟡 partial · ⏳ planned.

| Risk                                                 | Where it applies                                              | Mitigation                                                                                                                                          | Status | Evidence / planned verification                                                                        |
| ---------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------ |
| API1 Broken Object Level Authorization               | Saves, progress, sessions, downloads, account                 | User id only from the token; every query scoped by `userId`; random ids; 404 on foreign ids (C-23)                                                  | 🟡     | ✅ progress rows keyed by the authenticated user (`progress.ts`); SEC-AUTHZ-23 matrix ⏳               |
| API2 Broken Authentication                           | Register, login, refresh, reset, verification                 | Argon2id, Turnstile, throttling, EdDSA access JWT, rotating refresh with reuse detection (C-04–C-09, C-13–C-15, C-35)                               | ⏳     | SEC-AUTH-04…12, SEC-TOK-13/14/15, SEC-RST-35                                                           |
| API3 Broken Object Property Level Authorization      | Any body that could set roles, entitlements, ids              | `z.strictObject` rejects unknown fields; responses built from explicit DTOs, never raw rows (C-20)                                                  | 🟡     | ✅ strict schemas in `progress.ts`; SEC-IN-20 (extra field → 400) ⏳                                   |
| API4 Unrestricted Resource Consumption               | Every route; Argon2; email; saves; telemetry; R2              | Edge + app rate limits, body limits, no decompression, timeouts, quotas, budgets (C-03, C-05, C-07, C-11, C-20, C-21, C-24, C-26, C-31, C-38, C-39) | 🟡     | ✅ `routes.test.ts`, 16 kB body, 10 s timeout, 6000-row cap; SEC-IN-21, SEC-DOS-24, CFG SEC-COST-39 ⏳ |
| API5 Broken Function Level Authorization             | Admin/studio functions, entitlement-gated routes              | No admin routes in online-api; studio-api private (C-40); entitlement checks server-side (C-28)                                                     | 🟡     | ✅ `progress.test.ts` (full tier needs entitlement); CFG SEC-EDGE-40 ⏳                                |
| API6 Unrestricted Access to Sensitive Business Flows | Registration, checkout, reset, downloads, verification emails | Turnstile, per-account/IP velocity limits, email caps, download quotas (C-04, C-11, C-30, C-31)                                                     | ⏳     | SEC-AUTH-04, SEC-MAIL-11, SEC-PAY-30, SEC-DL-31                                                        |
| API7 Server Side Request Forgery                     | Outbound calls (payment fetch-back, HIBP, email)              | No user-supplied URLs; fixed hosts from config; outbound timeouts (C-24)                                                                            | ⏳     | Code review rule + SEC-DOS-24; grep test: no `fetch(` with request data in URL                         |
| API8 Security Misconfiguration                       | Headers, CORS, errors, TLS, cookies                           | `helmet`, generic errors, CORS allow-list, cookie attributes, TLS edge + internal (C-15, C-17, C-18, C-41)                                          | 🟡     | ✅ helmet, `x-powered-by` off, error handler; SEC-CORS-17, SEC-TOK-15, CFG SEC-HDR-18 ⏳               |
| API9 Improper Inventory Management                   | Undocumented or stale endpoints                               | Single route registry (`routes/index.ts`), OpenAPI per endpoint, no versionless or debug routes in prod                                             | ✅     | `routes.test.ts`; `openapi.json` generated from the registry; `openapi.test.ts` fails if stale ✅      |
| API10 Unsafe Consumption of APIs                     | Payment provider, email provider, HIBP, Turnstile             | Verify webhook signatures and fetch-back; validate third-party responses with Zod; timeouts; circuit breakers (C-27, C-24, C-39)                    | ⏳     | SEC-PAY-27, SEC-AUTH-04 (siteverify response validated), SEC-AUTH-08 (fail-open path)                  |
