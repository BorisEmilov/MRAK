# OWASP ASVS — Level 2 checklist

Target: **OWASP ASVS 4.0.3, Level 2**, for `services/online-api`, the game and landing as clients,
and the edge. Rows are grouped by ASVS section and summarise its L2 requirements; control ids
(`C-xx`) and tests (`SEC-*`) refer to the [threat model](threat-model.md). When moving to ASVS 5.0,
re-map these rows section by section.

Tests named below live in `services/online-api/src/auth/` (auth module coverage gate ≥ 90 % lines/statements in `vitest.config.ts`).

Results and open items: [test report](test-report.md). Status: ✅ done (evidence exists) · 🟡 partial · ⏳ planned (designed, not built) · N/A.
